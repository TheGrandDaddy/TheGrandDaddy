# Ari Sharone

I spent years running hospitality businesses and working in sales, learning marketing and branding. Now I build software for the problems I used to deal with on shift: scattered information, manual handoffs, and decisions that can’t wait until next week.

I run [The Regulars](https://bearegular.tech), where I help local businesses figure out what’s holding back growth and build the systems to fix it.

**What I’m building:**
- **HospitalityRD** makes restaurant sales and labor reports easier to use when planning shifts and reviewing service.
- **FaVela** gives a small editorial team one place to research, verify, script, and produce news videos, with a person reviewing the work at each editorial gate.
